### Docker build fix (blocked the user's own `docker compose up --build`)

`pnpm build` failed: `lib/actions/knowledge-embedding.ts` had `"use server"` at the top but exported a plain synchronous helper (`knowledgeEmbeddingCredential`) alongside the two actual async server actions. Next.js requires every export of a `"use server"` file to be an async function (each export becomes a callable Server Action reference). Fixed by splitting the file, mirroring the existing `lib/secrets.ts` (pure) / `lib/actions/secrets.ts` (`"use server"`) pattern: constants, types, and the pure helper moved to new `dashboard/lib/knowledge-embedding.ts` (no directive); `lib/actions/knowledge-embedding.ts` now contains only the two async actions. Updated the two import sites (`knowledge-embedding-section.tsx`, `settings-view.tsx`) accordingly. Confirmed no other `"use server"` file in the codebase has a non-async export (scanned all of them).
